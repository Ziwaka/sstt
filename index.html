📜 Version History

v1.3 (2026-11-06) — Data versions with restore: every cloud upload now saves a version you can restore from Settings. If the cloud changed elsewhere, the app now offers Export my copy, Load cloud, or Keep editing. Periods are clearer: each class shows whether it uses Global periods or its own list, Global edits show how many classes and lessons they affect, periods can be skipped without deleting lessons, and deleting a period shows its lesson count first. The lesson window shows the day, period and class. A teacher with no lessons gets an Add first lesson button, empty timetable cells open the add window, and a first-run guide shows the setup steps. Tabs and main buttons are now Burmese + English, sync buttons say what they do, and phone tap targets are bigger. Print stays landscape A4.
v1.2 (2026-11-06) — Data recovery: older cloud data now loads on a new device, an empty app can no longer overwrite your saved data, and Settings shows what the cloud holds.
v1.0 (2026-11-06) — Sync safety: realtime cloud updates, no silent overwrite, honest upload status. Safe import with backup and validation. Confirmations on destructive actions. Delete/rename cascades for classes, subjects and periods. Compressed logo. Pinned SortableJS with a safe fallback. Period and duplicate-name validation. Unique schedule IDs. Overlapping lessons shown. Print fixes: landscape kept until printing finishes, no blank print, custom vertical print. Holidays shown on Dashboard and print.
